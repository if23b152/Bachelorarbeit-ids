# Thesis outline

1. **Introduction** – motivation, short introduction to Suricata/Snort/Zeek, objectives, research question (RQ1–RQ3), relevance
2. **Methodology** – approach, lab setup (attacker, targets, sensor), scenarios, IDS configuration, evaluation scheme, comparison criteria, reproducibility
3. **General comparison of the tools** – virtual test environment, network, sensor VM, integration of Suricata, Snort and Zeek, installation effort
4. **Evaluation and comparison** – TCP SYN scan, Windows exploit scenarios (EternalBlue probe, SMB psexec), comparison tables, evaluation matrix
5. **Discussion** – answer to the research question, strengths, outlook, conclusion

The results are summarised in the [README](../README.md#results) and in [docs/results.md](../docs/results.md).
